<h1>Итоговая аттестация</h1>
<h2>Задание:</h2>

1. Требуется разработать фреймворк автотестов
2. Стек автоматизации (минимум):
  - Java
  - Любой HTTP-клиент
  - jUnit5
  - Allure
  - JDBC (можно использовать ORM любую)
  - Selenide/Selenium
<h2>Требования:</h2>

1. Есть инструкция, как запустить тесты из командной строки
2. Написан pipeline для запуска АТ (GitHub-actions / Jenkins)
3. Понятная структура пакетов:
  - тесты
    - api
    - ui
  - страницы (pageobject)
  - работа с бд
  - работа с апи
  - управление настройками
  - управление тестовыми данными
4. Понятный читаемый отчет
5. Оформлен файл readme.md
6. Оформлен файл .gitignore - в репозитории нет лишних файлов/папок
7. В качестве примера, во фреймворке есть api и ui-тесты (можно взять
тесты из промежуточных 3 и 4)
8. Тесты-примеры можно легко удалить из проекта и начать писать
автотесты под свой проект
<h2>Формат сдачи работы:</h2>

- ссылка на репозиторий в git
- в файле readme.md должна быть описана команда для запуска тестов (maven или gradle). 
Запускать буду через командную строку
- На портал приложен архив с репозиторием
- Презентация по шаблону
